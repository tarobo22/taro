# 여운 소개·문서·사용 안내

index.html을 열면 소개와 사용 영상을 목차별로 볼 수 있습니다. videos는 H.264/AAC MP4, subtitles는 한국어 WebVTT입니다.

문서6권과31쪽 통합본은 pdfs에 있습니다. 원본 기획·이전 모션 보고서·ERD/API 추적 자료는 references에 보존했습니다.

현재 상담은 직접 쓰기에서 입력합니다. 새 입력창·AI연동3안은 계획입니다. 앱·테스트·백엔드는 이번 작업에서 변경하지 않았습니다.

내레이션은 오프라인 한국어 합성음입니다. 영상의 음악·편집 효과는 실제 앱 감각 설정과 구분합니다.
