# 미디어 제작 근거

- 화면: 새 합성 게스트의 실제 React 웹 촬영. 기존 Android 화면은 이전 실행 증거로만 표기.
- 내레이션: Windows Microsoft Heami Desktop 오프라인 한국어 합성. 실제 GPT 음성·마이크 녹음 기능 시연이 아니다.
- 음악: 프로젝트 assets/audio/tarot_room.ogg를 낮은 음량으로 편집. 앱의 효과음·BGM 기본값은 변경하지 않음.
- 자막: 영상에 직접 표시 + 별도 UTF-8 WebVTT.
- 도해·예정 입력창: 코드로 그린 설명용 도해. 미구현 계획 표시.
- 캐릭터·카드: 기존 프로젝트 원본을 변경하지 않음. 기존 에셋 출처 자료의 권리 표기를 유지.
- 컷·멈춤·전환은 설명을 위한 편집이며 앱 성능 측정 영상이 아님.
