## 모션은 상태를 설명한다.
눈에 띄는 장식보다 탐색·선택·확정·취소를 구분하는 움직임을 사용한다.

| 장면 | 모션 기준 |
| --- | --- |
| 다이얼 | 직접 회전 → 제한된 관성 → spring 정착 → 값 rolling |
| 카드 선택 | 9dp lift·순서 슬롯 채움·선택 취소 역방향 |
| 셔플 | 서버 version 성공 뒤210ms 모으기·200ms 교차·330ms 펼치기 |
| 대화·스토리 | 약22% 임계값, 미선택 복귀, 선택 방향 퇴장 후 진입 |
| 확인 시트 | 진입280ms·퇴장180ms·핸들·뒤로가기 |
| 줄인 모션 | 회전·전환 즉시 정착·불필요한 반복 제거 |

이전 측정: 웹 RAF 콜백 p95약16.7~16.8ms. Android30.47초 녹화·캡처 포함 HWUI1740frames·jank2.01%·p9536ms·PSS331.4MiB. 서로 다른 측정 계층이며 실기기60fps 보증이나 이번 새 성능 측정이 아니다.

tick·선택·확정·경계 피드백을 구분한다. 영상에 편집으로 추가한 배경음·강조 효과와 실제 앱 설정은 구분해야 한다. 촉감 자체는 영상으로 재현하지 않는다.
