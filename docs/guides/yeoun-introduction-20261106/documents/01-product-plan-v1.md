오늘의 질문 → 카드·대화 → 작은 조언 → 마음기록

## 기능은 이용 목적에 맞춰 나눈다.
현재 사용할 수 있는 동작과 실제 서비스 연결이 필요한 영역을 함께 표시한다.

| 영역 | 현재 | 남은 일 |
| --- | --- | --- |
| 오늘의 한 장 | 주제 선택·확정 카드·기본 해석 | 실제 AI 해석 품질 검증 |
| 고민 타로 | 1/3/5장 설정, 3장 신규 Canvas 탐색 | 1·5장 기존 경로와 AI 계약 정합성 |
| 마음 대화 | 좌 아니요·우 예·직접 입력·기본 조언 | 주 버튼에서 입력창 열기 |
| 마음기록 | 감정 확인·글·저장·수정·원본 연결 | AI 요약 실제 품질·비용 평가 |
| 스토리 | 한 편·선택·결말·이어하기 | 추가 콘텐츠는 별도 기획 |
| 계정·결제 | 연결 코드와 관리 화면 | 공급자·스토어 등록·실사용 검증 |

기획1은 제품의 기준 문서다. 최초30쪽 기획의 시장·매출·과거 성능 조사는 새로 조사한 최신 수치로 바꾸지 않았다. 이번 문서는 현재 구현에 맞춘 요약·추적본이다.

진입 → 목적 선택 → 기능 수행 → 완료 확인

## 화면은 결과까지 끊김 없이.
성공 화면뿐 아니라 뒤로가기·취소·실패 상태까지 기능의 일부로 정의한다.

| 케이스 | 기본 흐름 | 예외 기준 |
| --- | --- | --- |
| 타로 | 설정 → 탐색 → 선택 → 공개 → 기록 | 선택 확정 전 앞면 비공개 |
| 대화 | 질문 → 좌우 선택/글 → 전송 → 조언 | 선택만으로 자동 전송하지 않음 |
| 기록 | 감정 탐색 → 확인 → 작성 → 저장 | 확인 취소는 기존 mood 유지 |
| 스토리 | 선택 → 진행 → 결말 | 나가도 서버 진행에서 이어가기 |

다음 상담 동선: 내 이야기 보내기 → 입력창·키보드 → 글/음성·선택 확인 → 별도 전송 → 처리 상태 → 답변. 이 동선은 계획이며 현재 앱에 구현하지 않았다.

## 버전별 산출물과 완료 조건.
기획·개발·개선·코드·사용법·AI 계획을 같은 이름으로 찾아볼 수 있게 연결한다.

| 묶음 | 보여줄 것 | 완료 기준 |
| --- | --- | --- |
| 기획안1 | 목표·사용자·요구·화면 흐름 | 현재/계획 범위를 한눈에 구분 |
| 개발안1 | 계층·API·DB·검증·배포 | 화면과 저장의 책임을 추적 |
| 디자인개선안2 | 수정 전후·토큰·모션 | 과장 없이 실제 화면 비교 |
| 코드변화2 | 동작 → 파일 → 커밋 | 변경 이유·보존 계약 명확 |
| 전체사용방법 | 8개 실제 케이스 | 처음 쓰는 사람이 따라 완료 |
| AI연동3안 | 기존 기반·확장 순서 | 실제 모델 검증 전 계획 표시 |

우선순위 제안: 상담 입력 동선 명세 → 1/3/5장·AI 계약 대조 → 기능별 AI 연결 → 제한된 실사용 평가 → 안내 영상 갱신. 이번 작업은 문서·영상 제작이며 앱 코드 변경은 없다.
