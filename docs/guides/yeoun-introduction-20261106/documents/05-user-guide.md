# 전체 사용방법
8개 실제 케이스로 따라 하는 여운
상태: 현재 앱 · 사용 안내

## 필요한 케이스부터 골라요.
모든 화면은 새 합성 게스트로 촬영했다. 실제 GPT·마이크·결제 호출은 하지 않았다.

| 케이스 | 완료할 일 |
| --- | --- |
| U01 | 처음 시작하기 |
| U02 | 오늘의 한 장 |
| U03 | 고민 타로 세 장 |
| U04 | 마음 대화와 글 입력 |
| U05 | 마음기록 저장과 수정 |
| U06 | 작은 쉼표 놀이와 이어하기 |
| U07 | 나에게 맞는 소리와 움직임 |
| U08 | 취소와 연결 실패에서 이어가기 |

영상은 실제 앱 촬영에 한국어 설명·자막·장면 전환·조작 강조·편집 배경음을 더한 안내 자료다. 촬영 속도는 성능 측정값이 아니다. 현재 앱의 상담 입력은 직접 쓰기에서 열며, 주 버튼에서 입력창을 여는 동작은 계획이다.

| 3. 내 공간에서 설정해요 | 내 공간에는 소리와 움직임 설정이 있어요. 계정과 구매는 연결 준비 상태를 먼저 확인해 주세요. |

| 3. 마음기록으로 이어가요 | 기본 해석을 읽고, 마음에 남은 내용을 기록으로 남길 수 있어요. 기록 저장은 직접 눌러 진행해요. |

## 고민 타로 세 장
영상 u03-tarot · 현재 앱 실제 조작

![ 시작·첫 동작 ](../shots/u03-tarot-01.png)
![ 결과·확인 ](../shots/u03-tarot-04.png)

| 단계 | 따라 하기 |
| --- | --- |
| 1. 주제와 질문을 정해요 | 주제와 카드 장수를 고르고 질문을 적어요. 이 영상은 현재 새 카드 탐색 화면을 사용하는 세 장 기준이에요. |
| 2. 돌려서 탐색해요 | 시작을 누르고 다이얼 테두리를 돌려 보세요. 카드를 탐색하는 것과 실제로 고르는 것은 다른 동작이에요. |
| 3. 세 장을 고르고 확인해요 | 카드 고르기를 세 번 눌러요. 위쪽 순서 칸을 누르면 선택을 취소할 수 있고, 다시 섞기도 가능해요. |
| 4. 확정한 카드의 이야기를 읽어요 | 선택한 카드의 이야기 듣기를 누르면 앞면과 기본 조언이 열려요. 앞면은 선택 확정 뒤에만 공개돼요. |

## 마음 대화와 글 입력
영상 u04-talk · 현재 앱 실제 조작

![ 시작·첫 동작 ](../shots/u04-talk-01.png)
![ 결과·확인 ](../shots/u04-talk-04.png)

| 단계 | 따라 하기 |
| --- | --- |
| 1. 좌우로 마음을 전해요 | 왼쪽은 아니요, 오른쪽은 예예요. 짧게 밀면 원래 자리로 돌아오고 버튼으로도 선택할 수 있어요. |
| 2. 현재는 직접 쓰기를 열어요 | 현재 화면에서는 직접 쓰기를 눌러 입력해요. 내 이야기 보내기에서 입력창이 열리는 동작은 다음 개선 계획이에요. |
| 3. 음성도 입력 수단이에요 | 음성 입력은 글을 쓰는 다른 방법이에요. 기기 권한과 지원 여부를 확인하고, 전송 전에 내용을 읽어 주세요. 이 영상에서는 녹음하지 않아요. |
| 4. 보낸 뒤 조언을 읽어요 | 내 이야기 보내기를 누르면 기본 가이드가 나와요. 지금의 조언과 작은 행동을 읽고 기록으로 이어갈 수 있어요. |

![ 시작·첫 동작 ](../shots/u05-journal-01.png)
![ 결과·확인 ](../shots/u05-journal-04.png)

| 단계 | 따라 하기 |
| --- | --- |
| 1. 마음을 골라 확인해요 | 다이얼이나 한 줄 목록으로 마음을 골라요. 선택 버튼을 누르고 확인해야 기록할 감정이 바뀌어요. |
| 2. 확인하고 한 줄을 적어요 | 이 마음으로 선택을 누른 뒤 글을 적어요. 확인 시트에서 취소하면 원래 감정 선택이 유지돼요. |
| 3. 저장을 눌러 남겨요 | 이 마음 저장하기를 눌러요. 저장된 상세 화면이 열리면 기록이 완료된 것이에요. |
| 4. 수정과 삭제 확인도 가능해요 | 기록 수정하기에서 내용을 바꾸고 다시 저장해요. 삭제는 별도의 확인 과정을 거치므로, 유지하려면 남겨 두기를 선택해요. |
